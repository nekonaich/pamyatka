# Памятка военнослужащего

Статический сайт: памятка с поиском, тексты трёх уставов по категориям, лекция и экзамен.
Работает без сборки и без сервера, достаточно GitHub Pages.

## Структура

- `index.html` — страница
- `css/style.css` — оформление (светлая и тёмная тема подхватываются автоматически)
- `js/data.js` — все данные: памятка (`MEMO`), лекция (`LECTURE`), уставы (`USTAV`), вопросы (`EXAM`)
- `js/app.js` — вкладки, поиск, экзамен
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (кнопка **New**), например `pamyatka`.
2. Загрузите в корень репозитория всё содержимое папки `site` (кнопка **Add file → Upload files**). `index.html` должен лежать в корне, а не во вложенной папке.
3. Откройте **Settings → Pages**.
4. В блоке **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сайт появится по адресу `https://ВАШ_ЛОГИН.github.io/pamyatka/`.

## Как править

Открывайте нужный файл на GitHub (значок карандаша), правьте и сохраняйте (**Commit changes**). Сайт обновится сам.

- Новый вопрос на экзамен: добавьте строку в массив `EXAM` в `js/data.js`. Первый элемент массива `a` — верный ответ, варианты перемешиваются при показе.
- Правка статьи устава: найдите её текст в `js/data.js` (раздел `USTAV`) и измените поле `html`.

## Примечания

- Шрифты (Oswald, PT Sans) подгружаются с Google Fonts. Без интернета сайт использует запасные шрифты.
- Поиск: клавиша `/` переводит курсор в строку поиска, `Esc` очищает.
